Chrome 安装教程

下载 zip，手动安装云篓。

当前版本可以通过 Chrome 的“加载已解压的扩展程序”安装。整个过程只需要几分钟，不需要命令行。

下载 material-hub-extension.zip 打开扩展管理页
01

下载插件压缩包

点击页面里的“下载插件”，得到 material-hub-extension.zip。

02

解压 zip

右键压缩包，选择“全部解压”或“解压到当前文件夹”。解压后会得到一个扩展文件夹。

03

打开 Chrome 扩展管理

在地址栏输入 chrome://extensions/，进入扩展程序页面。

04

开启开发者模式

在扩展程序页面右上角，打开“开发者模式”。

05

加载已解压的扩展程序

点击“加载已解压的扩展程序”，选择刚才解压出来的文件夹。看到“云篓”卡片后，安装就完成了。

06

固定云篓入口

点击 Chrome 右上角扩展图标，把云篓固定到工具栏。之后打开网页，就可以收集素材并进入侧边栏使用。

小提示

如果 Chrome 提示“清单文件缺失或不可读”，通常是选错了文件夹。请进入解压后的目录，选择里面包含 manifest.json 的那一层文件夹。
